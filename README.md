# Sample1

HTML/CSS/JavaScriptで作成したサンプルLP(ランディングページ)です。

## Demo

https://sample1-naruto1231.vercel.app

## 概要

企業・サービス紹介を想定したLPサンプルです。メインビジュアルのスライドショー、実績・写真ギャラリー、SNSリンクなどを含んだ構成になっています。

## 主な機能

- メインビジュアル・スライダー(`slide1〜3.jpg`)
- 実績/ギャラリーセクション(`photo01〜15.jpg`)
- プロジェクト紹介セクション(`imgProject.jpg`)
- SNSアイコンリンク(Facebook / Twitter / Instagram / YouTube)
- ロゴ差し替え対応(`logo〜logo04.png`)

## ファイル構成

- `index.html` : ページ本体
- `CSS/`, `style.css` : スタイルシート
- `script.js` : 独自スクリプト
- 画像素材一式(`bgSec04.jpg`, `mainImg.jpg`, `subImg.jpg`, `photo*.jpg`, `logo*.png`, `icon*.png` など)

## 使用技術

- HTML5
- CSS3
- JavaScript

## デプロイ

Vercelで公開中(GitHub Pagesでも過去にデプロイ実績あり)
